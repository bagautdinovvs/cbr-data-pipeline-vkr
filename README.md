# Автоматизированный пайплайн анализа стабильности банковского сектора (ЦБ РФ)

Данный проект представляет собой систему для автоматического сбора, обработки и визуализации данных отчетности коммерческих банков (форма 101) с официального сайта Центрального Банка РФ.

## Основные возможности
* **Авто-загрузка**: Скрипт `cbr_downloader.py` находит и скачивает актуальные архивы данных.
* **ETL-процесс**: Обработка сырых файлов DBF, агрегация показателей и загрузка в базу данных PostgreSQL.
* **ML-прогнозирование**: Построение прогноза уровня просроченной задолженности (NPL) на ближайшие 3 месяца.
* **Интерактивный дашборд**: Визуализация динамики активов, капитала и рисков на базе Streamlit.
* **Контейнеризация**: Полная упаковка всех сервисов (БД + Приложение) в Docker.

## Технологический стек
* **Language**: Python 3.11
* **Database**: PostgreSQL 15
* **Libraries**: Pandas, SQLAlchemy, Scikit-learn, Streamlit, Plotly
* **DevOps**: Docker, Docker Compose

## Как запустить

### 1. Предварительные требования
Установите [Docker Desktop](https://www.docker.com/products/docker-desktop/).

### 2. Запуск проекта
Склонируйте репозиторий и запустите контейнеры (терминал/vs code/jupyter и тп):
- git clone [https://github.com/bagautdinovvs/cbr-data-pipeline-vkr.git](https://github.com/bagautdinovvs/cbr-data-pipeline-vkr.git)
- cd cbr-data-pipeline-vkr
- docker-compose up -d --build

### 3. Обновление данных
Для запуска полного цикла обработки данных (Download -> Load -> Recalc -> Forecast) выполните:
- docker exec -it bank_app python run_pipeline.py

### 4. Просмотр результатов
После запуска дашборд будет доступен по адресу: http://localhost:8501

## Возможные проблемы
Есть вероятность, что данные на сайте ЦБ РФ отсутствуют или не парсятся. Альтернатива - ручная загрузка по ссылке https://www.cbr.ru/banking_sector/otchetnost-kreditnykh-organizaciy/ и сохранение разархивированных папок в виде подпапкок в raw
